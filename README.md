# Proyecto de Hacking Ético – DVWA

## Instalación y configuración

Para descargar e instalar **Damn Vulnerable Web Application (DVWA)**, sigue las instrucciones del archivo `README.es` incluido en la distribución de DVWA.

Lee cuidadosamente los requisitos y los pasos de instalación antes de continuar.

## Integración de los archivos de este repositorio

Una vez que hayas instalado y configurado DVWA correctamente, sigue estos pasos:

1. Descarga o clona este repositorio en tu equipo.
2. Localiza la carpeta donde quedó instalada DVWA.
3. Identifica las carpetas del repositorio que tienen el mismo nombre que las carpetas de tu instalación de DVWA.
4. Realiza una copia de seguridad de las carpetas originales.
5. Reemplaza las carpetas correspondientes de tu instalación por las versiones incluidas en este repositorio.
6. Si el sistema pregunta si deseas sobrescribir archivos existentes, confirma únicamente para las carpetas que forman parte de este proyecto.
7. Comprueba que DVWA siga funcionando correctamente y que los cambios del proyecto estén aplicados.

**Importante:** no reemplaces toda la instalación de DVWA. Sustituye únicamente las carpetas que están incluidas en este repositorio y que corresponden a las indicadas por el proyecto. Conserva los archivos de configuración propios de tu instalación, especialmente los que contienen los datos de conexión a la base de datos.

## Consideraciones

- Este proyecto está destinado a fines educativos y de aprendizaje de hacking ético.
- Las pruebas deben realizarse exclusivamente en el entorno local de DVWA autorizado para el proyecto.
- Se recomienda conservar una copia de seguridad de los archivos originales antes de reemplazarlos.
- No utilices las modificaciones de este proyecto en sistemas sin autorización.
